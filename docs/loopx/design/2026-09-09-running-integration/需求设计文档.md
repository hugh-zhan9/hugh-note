## 四、详细设计

### 4.1 活动导出与消费

入口为 Vite dev middleware 和生产构建插件。解析原 JSON，验证数组与消费者必需字段：run_id/name/type/start_date/start_date_local/distance/moving_time/average_speed/elevation_gain/streak，以及可选 summary_polyline/location_country。距离/速度有限非负，时间可解析，ID 唯一。执行原展示修正后将 type 标准化，保留其余字段。客户端非 2xx 或非数组为加载失败。空数组合法。HTTP 请求使用重新校验缓存，部署时数据与代码来自同一源提交。

边界：0/1 条、空月、年份跨界、缺轨迹、不合法记录。源码与数据库不被构建写回；旧修正规则保持。

### 4.2 外观适配

共享控制器在 head 执行以免闪色；React 通过全局窄接口读取偏好和订阅，不再挂载外观面板。主页的 SVG 图标入口保留原生 details 键盘操作、可访问名称与焦点提示。明暗地图底图保留；自定义背景的面板文字使用独立表面前景色。

边界：非法 HEX 不写偏好；受限存储仍能当页使用；旧偏好只迁移一次；纸色和鼠尾草切换也触发图表重绘。既有首页月份/路线按钮和文章排版保持。年度总结恢复源仓库的独立 CSS，局部保留原字体，路由不渲染全站导航；从普通跑步导航可进入默认的已完成年度，年份选择继续复用原有逻辑。年度总结在预设、自定义色及跨标签切换下均保持自己的样式，不写回主题偏好。

### 4.3 构建与同步

构建可通过 HUGO_BIN 指向 Hugo Extended；根脚本从任意工作目录定位仓库，不在源码目录生成发布内容。预览只读组合产物。CI 在校验完整构建后发布，凭据仅存在任务环境。同步不重试冲突、不吞掉同步/推送失败。

边界：任一构建失败不替换当前 dist/site；发布前检查 main，过期构建跳过。深链接仅允许同源 /running/，无开放重定向；博客 404 不接管为跑步页。

## 七、接口设计

GET `/running/data/activities.json`：公开只读数组，单位保持 distance 米、average_speed 米/秒，start_date_local 保留原本地日期字符串，type 为既有 normalizer 的规范值。summary_polyline 为空表示无轨迹，不补坐标。原有附加字段保持，以支持年度总结和地图；无认证信息进入响应。两个消费者在失败时保持各自已有错误显示，不将错误变成空列表。

## 八、系统发布

切换/回滚遵循概要 D-004/D-005：关闭旧更新与 project Pages，开启新同步并发布统一产物。回滚为恢复旧发布配置与旧站、关闭新同步；不回滚或覆盖新增活动数据。此操作需另行发布授权。

## 十、排期与规划

### 10.5 Planning Handoff

计划可决定局部文件名、CSS 适配与测试组织，须保留五项架构约束。新增存储、更改公开路径或历史数据语义返回 spec。实现工作跨多个阶段，使用持久计划保证中断恢复。

## 十一、QA

### 11.2 待确认问题

无阻塞实施问题；线上切换与 secrets 验证保留为发布阶段工作，不在本轮执行。

### 11.3 Verification Strategy

D-001: 导入与源仓库受保护文件哈希一致，跑步原测试。D-002: skins 单测和浏览器跨页/标签/明暗底图。D-003: 数据导出边界测试、主页真实数据而非旧 JS mock。D-004: 组合产物、深链接/查询/404/移动端。D-005: 工作流解析与离线 Python 测试、文件暂存范围检查；真实 Keep 和线上切换不执行。

### 11.4 Design Contract Index

D-001 模块/数据所有权；D-002 共享外观；D-003 只读数据接口；D-004 组合发布/路由；D-005 同步和切换。所有锚点均归 [概要设计](概要设计.md) 对应标题，本文件提供字段与边界细节。
