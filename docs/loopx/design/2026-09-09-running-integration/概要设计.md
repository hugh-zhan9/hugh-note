# 跑步应用同仓整合概要设计

版本 v1.1，2026-09-09。同仓整合已在工作树实现；本次按用户明确要求修订外观入口和年度总结样式。

## 1. 背景与范围

Hugo 博客基线为 5f27dd6；running 基线为 0e2c77a，上游同步至 1639f8b。统一主题、导航、数据接口、预览与发布，保留两种技术栈。用户确认依据为本次会话的评估及“这种模式我认可”。本轮实施不包含 Git 提交、线上发布、关闭旧仓库或操作 Keep 账号。

## 2. 总体设计

### D-001 模块边界（Operational Contract）

Hugo 继续拥有文章与主页，`apps/running` 完整承接 running 的受版本控制文件（不复制 .git、依赖、缓存）；Python 同步、SQLite、GPX 和原始 JSON 仍由跑步模块唯一维护。构建只读取这些记录，禁止修改历史数据、推断室内记录或补造坐标。来源：用户认可的同仓独立应用方案。维护代价：上游按记录的提交与目录进行内容三方合并，保留许可证和来源说明。

### D-002 共享外观（Behavior Contract）

扩展现有 `static/js/themetoggle.js` 控制器及 `assets/css/skin.css` 的颜色定义，复用 tokens；Hugo 主页独占面板 HTML 与样式，React 只订阅配色，各自维护页面布局。`theme-storage` 是唯一偏好；已有博客偏好优先，仅在没有该键时迁移 running 的 light/dark 偏好，之后不写旧键。明暗属性与 Dashboard class 由同一个控制器设置；地图订阅明暗变化。外观入口仅出现在 Hugo 主页，使用带可访问名称的图标按钮。年度总结由 Classic summary 页面独立维护原有深色渐变、橙色强调、字体和全屏翻页，不读取站点配色，也不改写偏好；普通跑步导航保留年度总结入口，复用既有 metadata 年份选择逻辑。默认素纸、自定义色、跨标签同步、存储受限反馈保持。

### D-003 数据接口（Data / Interface Contract）

跑步构建插件从 `src/static/activities.json` 读取记录，复用 `src/utils/activity.ts` 的展示修正和类型规范化，生成 `/running/data/activities.json`。两个前端均只读取此生成接口；Hugo 不依赖跑步的 JS bundle 格式。该接口是只读投影，不是第二个可写数据源；详细字段和失败契约见需求设计文档 §7。

### D-004 组合发布和路由（Operational Contract）

构建固定 `/running/` 前缀，Hugo 与 Vite 产物在临时目录组合，全部成功后才形成发布产物；只有根仓库现有 external_repository 发布流程写站点。根 404 仅对 `/running/` 内的深链接进行命名空间内恢复，保留查询和 hash，其余博客 404 保留。常用 summary 路由生成真实入口以支持直接访问。预览提供同样路由行为，不使用线上数据代理。

## 3. 分模块方案

主题适配集中在跑步 `src/site/`，复用 Classic 功能组件；Dashboard 注册入口保留并共用外观偏好。数据导出插件归跑步模块，拒绝非法 JSON/记录而非输出空记录。主页继续区分空月与失败，月份、路线、地区筛选保留。

### D-005 同步及切换（Operational Contract）

现有 Keep 每日任务移入根工作流，从 `apps/running` 工作目录调用原脚本，沿用原生成参数。凭据通过 Actions secrets 与环境变量传递，永不进入构建产物。只暂存跑步生成文件；同步失败不提交/发布，push 冲突直接失败。同步使用 main 最新代码并在成功后调用统一发布工作流；部署串行且检查当前 main，避免旧构建覆盖新提交。新同步任务受 `RUNNING_SYNC_ENABLED` 仓库变量控制，默认关闭，待实际切换时开启；切换需迁移 secrets、停止旧定时任务并关闭旧 project Pages，以免 URL 遮蔽新目录。该外部操作不在本轮授权内。

## 4. 改动清单

新增 apps/running、跑步构建适配、共享面板源、站点构建/预览脚本与集成测试；修改主题控制器、主页数据加载、根 Actions。无数据库结构变化。

## 5. 对外影响与配合

代码交付可本地完整运行。实际发布切换应先获取用户发布授权，按 D-005 操作旧站与 secrets；不因实施授权推定发布授权。

## 6. 风险与决策状态

已确认方向，无阻塞实施的产品决策。GitHub Pages 路由优先级和外部 secrets 属于上线验收；本地验证不能代替线上验收。大地图依赖及上游维护成本保留，不重写框架。

## 7. 验收

默认/预设/自定义主题在主页、文章和普通跑步页面一致；外观图标仅在主页存在，年度总结保持原样且入口可达；深链接刷新保留查询；真实构建 JSON 驱动主页月份/路线切换；错误数据不伪装空月；导入历史文件哈希一致；23 项跑步测试、类型检查、博客测试、Python 离线测试、组合构建和浏览器检查通过。
